Privacy at OpenKrillion

This independent game can be played without an account. We use a random browser identifier, not a name or email, to resume a dive. This page describes the implemented service.

Game progress

Preferences, draft answers and a copy of completed history are stored locally in your browser. The server stores your random identifier, game date, accepted answers, scores and round timing in Cloudflare D1. Clearing browser storage removes the local copy and identifier. There is no cross-device login or account sync.

Statistics and feedback

Daily score comparisons use completed daily games on OpenKrillion. Practice scores are excluded. Voluntary ratings and suggestions are saved if submitted; do not include personal information.

Analytics

This site uses Plausible on analytics.howtosurvive.ai, Google Analytics 4 and Microsoft Clarity when their production integrations are enabled. They measure page visits, game events and site usability. Clarity is configured to mask typed input; answer text is not attached to analytics events. Analytics scripts are disabled on localhost and automated test runs. Browser content blockers do not prevent the game from working.

Hosting and references

Cloudflare hosts the application and D1 database. R2 stores assets and reference puzzle snapshots. Public reference categories and answer lists may be synchronized from krillion.io. No user answers are sent to that reference service.

Cookies

The essential ok_player cookie is HttpOnly, SameSite=Lax and Secure on HTTPS. It identifies a browser's game history. Third-party analytics may use their own storage and cookies.

Retention and requests

Game records are retained for history and statistics. Rate-limit records are short-lived. For a data request, open a repository issue without posting personal information; arrange private details separately. We do not sell player records. We collect no payment information because checkout is not implemented.

External AI links

AI icons open third-party services with a public product question. Opening them shares that question with the selected provider. No game answer, identifier or private history is included.
