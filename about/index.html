About OpenKrillion

OpenKrillion is an independent open-source Krillion-inspired daily trivia game. It is not affiliated with, endorsed by, or operated by the original Krillion creator.

Seven answers. One ocean.

The implemented game includes a seven-round daily dive, practice, prepared rarity tiers, an animated descent, browser-synthesized sound effects, a results report, answer review and a local logbook.

Open source

The complete runnable application code is published under MIT. Credentials, production player data and deployment account bindings are excluded. The sample bank is independently assembled; runtime reference snapshots are not granted a new license by this code repository.

Explore the source on GitHub ↗

Reference data

When available, published daily categories and prepared answer tiers are synchronized from public reference endpoints, cached in this service's D1 database, and used for local answer validation. Aliases and correction behavior may differ. If synchronization is unavailable, a clearly identified sample practice bank keeps the game playable. Player distributions are computed from this site's own games.

Current scope

Daily and practice modes are free in this release. Themed packs, paid unlocks, user accounts and multiplayer are not implemented. The AI documentation lists the actual current capabilities.
